# 📊 Kimia Farma Big Data Analytics

## 📌 Deskripsi
Project ini bertujuan untuk menganalisis data penjualan Kimia Farma menggunakan BigQuery dan divisualisasikan menggunakan Looker Studio.
---
## 🛠 Tools
- Google BigQuery
- Google Looker Studio
---
## 📂 Dataset
- kf_final_transaction
- kf_inventory
- kf_kantor_cabang
- kf_product
